    FROM DISCOVERY TO DOING

    Your next capability.
    Four simple steps.

    Run these commands in your own project. This marketplace supplies reusable guidance; you choose what your agent uses.

    Read the APM installation guide ↗

    1. Install the APM CLI

      Choose the supported installer for your operating system.

      Get APM ↗

    2. Set GitHub authentication for APM

      After gh auth login --hostname github.com, use the intended account's credential in this terminal:

      PowerShell

      $env:GITHUB_APM_PAT = gh auth token --hostname github.com

      Bash / Zsh

      export GITHUB_APM_PAT="$(gh auth token --hostname github.com)"

      For a particular saved account, add --user ACCOUNT to the gh auth token command. Run APM in the same terminal. These assignments capture the token without displaying it; never paste its value into chat or commit it.

      Public github.com packages need no token. Current APM can also use your active GitHub CLI login directly; this variable explicitly supplies its credential. Preserve any existing injected credential unless you intend to replace it. APM authentication guide ↗

    3. Connect the marketplace

      apm marketplace add EqualExperts/apm

      Use a GitHub account with access to this repository.

    4. Choose a capability

      Tick the capabilities you need, choose your assistant in Your toolkit, and copy the generated install script. For a stack, review every included package first.

      Review source and revisions before adoption. Target selection is not a claim of verified compatibility.
